# Quickstart

## Prerequisites

- [Bun](https://bun.sh/) installed on your system
- Git for cloning the repository

## Installation

1. **Clone the repository**

```bash
git clone https://github.com/aliammari1/freecodecamp-portfolio.git
cd freecodecamp-portfolio
```

2. **Install dependencies (one Bun workspace, one lockfile)**

```bash
bun install
```

3. **Set up environment variables (per service that needs them)**

```bash
# only exercise-tracker / url-shortener ship a sample.env
cd exercise-tracker && cp sample.env .env
# Edit .env (e.g. MONGO_URI) as needed
```

4. **Start a service in watch mode**

```bash
cd timestamp && bun run dev   # each service runs independently on PORT 3000
```

## API Documentation

Each API serves an interactive Scalar reference at `/api-docs` and the raw
OpenAPI spec at `/api-docs.json`. Once running, visit:

```
http://localhost:3000/api-docs
```

## Testing the APIs

### Exercise Tracker

```bash
# Create a user
curl -X POST http://localhost:3000/api/users \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=johndoe"

# Add exercise
curl -X POST http://localhost:3000/api/users/USER_ID/exercises \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "description=Running&duration=30&date=2024-01-01"
```

### Timestamp

```bash
# Convert date
curl http://localhost:3000/api/2024-01-01

# Current time
curl http://localhost:3000/api/
```

### URL Shortener

```bash
# Shorten URL
curl -X POST http://localhost:3000/api/shorturl \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "url=https://www.example.com"
```

## Project Structure

Each API follows the same structure:

```
service-name/
├── app.js            # createApp() factory (testable, Worker-reusable)
├── index.js          # listen-only entrypoint
├── swagger.js        # swagger-jsdoc OpenAPI config
├── gen-openapi.js    # writes openapi.json
├── test/             # bun:test + supertest
├── package.json      # dependencies and scripts
├── public/           # static assets
└── views/            # HTML templates
```

> The lockfile lives at the repo root (`bun.lock`) for the whole workspace.
