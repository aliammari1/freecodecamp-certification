# FreeCodeCamp Portfolio

Welcome to the FreeCodeCamp Backend API Portfolio! This monorepo contains five microservice APIs built as part of the freeCodeCamp Back End Development and APIs certification.

## What's Inside

This portfolio demonstrates fundamental backend development concepts through practical, working APIs:

<CardGroup cols={2}>
  <Card title="Exercise Tracker" icon="running" href="api-reference/exercise-tracker">

## Features

- **RESTful APIs** - Clean, predictable resource-oriented endpoints
- **Interactive Documentation** - A Scalar API reference is available at `/api-docs` for each service, and the raw OpenAPI spec at `/api-docs.json`
- **Cross-Origin Support** - CORS enabled for client-side testing
- **Modern Tooling** - Bun workspaces for fast installs, Biome for linting, bun:test for tests

## Quick Start

Each API is self-contained and can be run independently. Check out the [Quickstart](/quickstart) guide to get up and running in minutes.

## Architecture

```
freecodecamp-portfolio/
├── exercise-tracker/     # MongoDB + Express exercise tracking API
├── file-metadata/        # File upload and metadata extraction
├── header-parser/        # HTTP header parsing microservice
├── timestamp/            # Date conversion microservice
├── url-shortener/        # URL shortening microservice
└── docs/                 # Mintlify documentation
```
